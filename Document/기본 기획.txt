정식으로 지원되는 로스터 빌더 앱이 있으나, 사용에 불편함이 있어 직접 새로운 로스터 빌더 앱을 구현해보고자 한다.

# 기존 앱 문제

- 로스터 여러개 관리 불가
- Cp 소모 정보나 각종 능력들이 어느 페이즈에 사용되는지에 대한 설명이 빠져 있음
- 각종 키워드에 대한 정보를 찾기 어려움
- 실제 게임 시 이 앱을 참조하여 플레이하는 것은 불가능한 수준
    - 정보의 디테일이 부족하기 때문
    - 정보 탐색의 편의성이 매우 떨어지기 때문

# 화면 구조

## 로스터 빌더 화면

- 팩션 및 택티컬 카드, 유닛 카드 별 정보 상세 확인 가능
    - 유닛의 경우 업그레이드 선택 기능 제공
- 여러개의 로스터 작성 가능
    - 로스터 별 미네랄 설정 가능
- 한 눈에 파악 가능한 로스터 상태
- 이미지 형태로 로스터를 출력하는 기능

## 게임 화면

- 팩션 및 택티컬 카드를 같은 열로 보여줌
    - 카드 정보 완전히 포함
    - 클릭 시 뒷 면을 보여줌
    - 카드 별 우측 위 오버레이 ? 버튼 클릭 시 상세 정보를 띄움
    - 카드 리스트 한 쪽 끝에 되돌리기 버튼이 제공되며, 누를 시 모두 앞면으로 돌아옴
- 유닛 카드 보여줌
    - 카드 정보 완전히 포함
	- 선택한 업그레이드가 완전히 적용됨
	- 선택되지 않은 업그레이드 및 업그레이드로 인해 필요 없어진 정보는 표시되지 않음 (불필요한 정보 차단)
    - 카드 별 우측 위 오버레이 ? 버튼 클릭 시 상세 정보를 띄움
- 화면 하단에 ‘페이즈 강조’ 버튼 제공
    - 화면 전체 스크롤과 상관 없이 보여짐
    - 페이즈 클릭 시 해당 페이즈에 사용 가능한 액션만 표시됨
